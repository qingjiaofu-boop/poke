# STC-B Gomoku Firmware

Keil C51 project for the STC-B board. Open `STC_BSP_Gomoku.uvproj` and build the `STC-B Gomoku` target. The generated HEX is placed in `output/STC_BSP_Gomoku.hex`.

The `inc` folder contains the course BSP headers and `STCBSP_V3.6.LIB` is the linked library. Do not remove either when moving the project to another computer.
